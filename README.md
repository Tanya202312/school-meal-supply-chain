# School Meal Supply Chain Platform

> A proposed digital platform to simplify school meal ingredient ordering and improve communication between schools and food suppliers.

## Problem & Users

School meal supply chains involve schools, nutritionists, manufacturers, suppliers, and distributors. Information is often stored in different formats, causing repeated manual work and communication problems.

The platform is designed for school nutritionists, food suppliers, distributors, and manufacturers.

## Features / Solution

- Centralized ingredient and product information
- Digital order management
- Improved communication between stakeholders
- AI-assisted product data standardization
- Reduced manual data entry

## Architecture

The proposed system connects three main components:

1. **Data Repository:** Stores ingredient and supplier information.
2. **Order Management:** Organizes orders between schools and suppliers.
3. **AI Data Processing:** Helps identify equivalent products with different names or formats.

## Prerequisites

For a future prototype:

- Python 3
- A database for product and order information
- Sample ingredient and supplier data

## Installation

The platform is currently a concept project. Installation instructions will be added when a working prototype is available.

## Quick Start / Usage

The proposed workflow is:

1. A supplier uploads ingredient information.
2. The platform organizes product data.
3. A nutritionist searches for ingredients and prepares an order.
4. The supplier receives the order.
5. Order information is updated in the system.

## Example Output

An example order summary could include:

- School: ABC Elementary School
- Product: Rice
- Quantity: 20 kg
- Order Status: Submitted

## Data / Model

The platform would use product descriptions, ingredient quantities, supplier records, and order information.

AI-assisted matching could help standardize different descriptions of the same product. Suggested matches would require validation.

## Limitations

- The platform is currently a proposed concept.
- No working software has been implemented.
- AI matching may produce incorrect results.
- Data quality depends on information provided by suppliers.
